# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/ikyucom/kseal/security/advisories/new),
not in a public issue. Include what is affected, how to reproduce it, and the
impact you see.

## Supported versions

Fixes go into the latest release only.

## Scope

What kseal does and does not protect is described under
[Security](README.md#security) in the README; a report that a documented
non-goal holds (for example, that whoever can decrypt with the key can read
values) is not a vulnerability.
